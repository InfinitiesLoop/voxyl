# Setting up an AI agent, then watching it build.

[intro]
Want an AI to build alongside you? voxyl is an MCP server, so agents like Claude Code or Codex can drive it directly.

[settings]
Open Settings and switch on agent connections. voxyl hands you the exact command to run.

[copy]
Copy it, paste it into a terminal once, and you're connected.

[badge]
Now a little badge shows an agent is attached.

[ask]
Then just ask. It builds live, right in your window.

[undo]
Every edit is an undo step, and you can pause the agent whenever you like.

[end]
You stay in charge. The agent does the typing.
